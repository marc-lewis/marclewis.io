# marclewis.io
domain homepage

The homepage is minesweeper, wall to wall. The tilted sheet of linkedin
buttons fills the viewport, laid in running bond like brickwork; click
anywhere and the playable field defines itself out of the wall, the rest
fading into scenery. Click to dig, right-click (or hold, on touch) to
flag. Numbers count only the bricks that truly touch - six neighbours,
not eight. The first dig is always safe and clears a pocket. Hit a bomb
- or clear the board - and you're outta here, straight to LinkedIn.
