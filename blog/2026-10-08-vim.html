In this era of AI coding I'm going back to basics to make sure I can still remember what those basics are. Whichever AIs and Agents I use at work will slowly erode away all of my skill as my work becomes reviewing PRs, thinking about product, and thinking in terms of systems.

I'm introducing a number of constraints to build this site so that I can feel like a programmer. And what that feels like to me is this ridiculous setup:

  • Only using Vim to code the site by hand, no generative AI that I just review
  • Coding the site in C and running it through WASM
  • Learning and writing algorithms again to get back to that feeling of Advent of Code and CTCI
  • Doing something with obsolete hardware like floppy disks to store media, or run the site from in some way (even if it's just storage)
  • Implementing a novel design for the site so that people can interact with it and have moments of joy

All I've done so far is spin up NVim and I can feel the pain of the ramp up time. So far I'm depending on $^ai and /. It is slow and arduous, but I look forward to chains of commands and learning to be efficient over the coming years. I don't even have line numbers, a file tree, but I will start slowly ripping plugins from lazyvim for anything I think is missing so far. One day I will delete VSCode and stop using my mouse.
